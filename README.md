# The Weeknd · After Hours Til Dawn — E-App Tiket (sisi user)

## Menjalankan (Mac / VS Code)
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python main.py
```
Butuh Python 3.10+ dan Google Chrome.
